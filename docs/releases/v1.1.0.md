# Grandia III 한국어 패치 v1.1.0

Grandia III 일본판 Disc 1용 비공식 한국어 패치의 안정판 업데이트입니다. v1.0.0의 모든
누적 수정에 검색 튜토리얼 버튼 표시 교정과 GRM10 영상 자막 전체 재동기화를 추가했습니다.

## 변경 사항

- `DATA/00061000.MDZ`의 검색 튜토리얼에서 빈칸으로 나오던 버튼을 `□` 아이콘으로 복원
  - 잘못 중복 변환된 `<G08B8>` 두 곳만 `D8 F9`에서 `B8 F9`로 교정
  - 디코딩 MDT 크기와 레코드 배치 보존
  - `SYS/GR3.MDZ`와 `텐` 글리프 슬롯은 v1.0.0과 byte-exact
- `MOVIE/GRM10.MOV`의 한국어 하드서브 17개를 음성 기준으로 전체 재동기화
  - 원본 PS-ADPCM 음성 3,301개 섹터 byte-exact 보존
  - MPEG2 프로그램 스트림 구조 검증 통과
- v1.0.0의 시스템·아이템·전투·시나리오·카지노·비행·렌더링 이벤트 자막과 영상 수정 유지

## 배포 파일

GitHub Release에는 다음 6개 파일만 제공합니다.

- `Grandia3_KR_Disc1_v1.1.0_0a1ec442_full.xdelta`

- `README_ko.md`

원본 ISO, 완성 ISO, MOV/MDZ/MDT/BIN과 추출 게임 자산은 배포하지 않습니다.

## 정적 검증

- 고정 CLEAN 원본과 고정 v1.0.0 부모의 크기·SHA-256 확인
- v1.0.0에서 정확히 `DATA/00061000.MDZ`, `MOVIE/GRM10.MOV` 두 엔트리만 교체
- 최종 ISO 이중 생성 결과 byte-identical
- 원본과 결과 ISO 크기 동일, 1,266개 파일 경로와 모든 extent 보존, relocation 0
- ISO9660/UDF 및 독립 7-Zip 역추출 byte-exact
- 공용 폰트, 실행 파일, 전투·비행·자막 컨테이너 등 핵심 상속 파일 byte-exact
- CLEAN 원본에서 xdelta 복원 후 결과 SHA-256과 전체 byte 비교 일치
- macOS/Linux 적용 스크립트를 CLEAN 원본에 end-to-end 실행하고 목표 ISO와 일치 확인

누적 기능은 개발 중 반복 실기 확인했습니다. 이번 v1.1.0에서 새로 결합한 검색 버튼 표시와
GRM10 전체 재동기화는 정적·역검증을 통과했으며 사용자 최종 실기 확인 대기 상태입니다.
